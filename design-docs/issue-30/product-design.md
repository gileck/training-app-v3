  "design": "# Product Design: Exercise Definition Overrides in Training Plans\n\n**Size: L**\n\n## Overview\n\nThis feature enables users to customize exercise definitions on a per-exercise basis within their training plans. When users add an exercise to their plan, they can override properties like name, muscle groups, image, and exercise type without affecting the original exercise definition. This allows users to create personalized variations (e.g., \"Bench Press - Heavy\" vs \"Bench Press - Light\"), reclassify muscle groups to match their technique, and add the same base exercise multiple times with different configurations.\n\n## User Stories\n\n- As a user, I want to customize the name of an exercise in my plan so I can distinguish between variations (e.g., \"Close-Grip Bench Press\")\n- As a user, I want to change the muscle group classification for an exercise to match how I actually perform it\n- As a user, I want to add the same exercise twice with different names and configurations\n- As a user, I want to reset my customizations back to the original exercise definition\n- As a user, I want to clearly see which exercises have been customized\n\n## UI/UX Design\n\n### Entry Points for Override Configuration\n\nUsers can access the override configuration in two scenarios:\n\n**1. When Adding a New Exercise**\n\nAfter selecting an exercise from the library in the Add Exercise Dialog, the existing \"Configure Exercise\" step (ExerciseConfigForm) will be enhanced:\n\n- Current fields remain: Sets, Reps, Weight, Notes\n- New expandable section: \"Customize Exercise\" (collapsed by default)\n- Expanding reveals override fields for the exercise definition\n- Users can configure workout parameters without touching overrides (most common case)\n\n**2. When Editing an Existing Exercise**\n\nThe existing Edit Exercise Dialog will be enhanced:\n\n- Current fields remain: Sets, Reps, Weight, Notes\n- New \"Customize\" button in the header area (next to exercise name/image)\n- Tapping opens a dedicated \"Customize Exercise\" sheet/dialog\n\n### Customize Exercise Interface\n\nA dedicated interface for overriding exercise definition fields:\n\n**Header Section**\n- Exercise image (tappable to change)\n- Exercise name input field (pre-filled with current name)\n- Clear visual showing \"Customizing [Original Exercise Name]\"\n\n**Override Fields**\n- **Name**: Text input, pre-filled with original name\n- **Image**: Image upload area (same pattern as Create Exercise Dialog - upload or paste)\n- **Primary Muscle**: Dropdown/select from muscle list\n- **Secondary Muscles**: Multi-select chip buttons (same pattern as Create Exercise Dialog)\n- **Exercise Type**: Dropdown (Strength, Cardio, Flexibility, Balance, Plyometric)\n- **Bodyweight**: Checkbox toggle\n- **Static/Timed**: Checkbox toggle\n\n**Visual Indicators for Overridden Fields**\n- Each field that differs from the original shows a small \"Modified\" badge or dot indicator\n- Tapping the indicator reveals the original value and offers \"Reset to default\" action\n\n**Footer Actions**\n- \"Reset All to Defaults\" button (secondary/outline style) - requires confirmation\n- \"Cancel\" button\n- \"Save Customizations\" button (primary)\n\n### Reset Confirmation Dialog\n\nWhen user taps \"Reset All to Defaults\":\n- Simple confirmation dialog: \"Reset all customizations?\"\n- Body text: \"This will restore all fields to the original exercise definition values.\"\n- Actions: \"Cancel\" and \"Reset\"\n\n### Visual Indicators in Exercise List\n\nExercises with overrides need visual distinction in the plan exercise list (PlanExerciseCard):\n\n**Customized Exercise Indicator**\n- Small badge/icon overlay on the exercise card (e.g., a small pencil icon or \"Customized\" badge)\n- Position: Top-right corner of the exercise image, or next to the exercise name\n- Subtle but noticeable - uses primary color at reduced opacity\n\n**Card Display**\n- Shows the overridden name (not original)\n- Shows the overridden muscle group badge\n- Shows the overridden image (if changed)\n- Original exercise name can be shown as small secondary text: \"Based on: [Original Name]\"\n\n### Multiple Instances of Same Exercise\n\nWhen the same base exercise is added multiple times:\n\n- Each instance appears as a separate card in the list\n- Each can have different overrides and workout configurations\n- The \"Based on: [Original Name]\" indicator helps users understand they're variations of the same base exercise\n- No special grouping - they appear in their natural order position\n\n### User Flow: Adding Exercise with Customization\n\n1. User opens Add Exercise Dialog\n2. User browses/searches and selects an exercise\n3. Configure Exercise screen appears with workout parameters (sets, reps, weight)\n4. User notices \"Customize Exercise\" expandable section at bottom\n5. User expands section to see override fields\n6. User modifies desired fields (e.g., changes name to \"Incline Bench Press - Slow\")\n7. Modified fields show \"Modified\" indicator\n8. User taps \"Add to Plan\"\n9. Exercise appears in plan with customized values and \"Customized\" badge\n\n### User Flow: Editing Existing Exercise Customizations\n\n1. User taps on an exercise card in their plan\n2. Edit Exercise Dialog opens showing workout parameters\n3. User taps \"Customize\" button in header\n4. Customize Exercise sheet slides up\n5. User sees all override fields with current values\n6. Modified fields show indicators with option to reset individually\n7. User makes changes or resets fields\n8. User taps \"Save Customizations\"\n9. Returns to Edit Exercise Dialog with updated preview\n10. User taps \"Save Changes\" to confirm all changes\n\n### User Flow: Resetting Customizations\n\n**Reset Individual Field:**\n1. In Customize Exercise interface, user taps \"Modified\" indicator on a field\n2. Popover/tooltip shows: \"Original: [value]\" with \"Reset\" button\n3. User taps \"Reset\"\n4. Field immediately reverts to original value\n5. \"Modified\" indicator disappears\n\n**Reset All Fields:**\n1. User taps \"Reset All to Defaults\" button\n2. Confirmation dialog appears\n3. User confirms\n4. All fields revert to original values\n5. All \"Modified\" indicators disappear\n6. If no overrides remain, the \"Customized\" badge will be removed from the exercise card\n\n### Loading and Error States\n\n**Loading States:**\n- When saving customizations: Button shows \"Saving...\" with spinner\n- When loading muscle groups list: Skeleton placeholders in dropdown\n\n**Error States:**\n- Save failure: Toast notification \"Failed to save customizations\" with retry option\n- Image upload failure: Inline error message below image upload area\n- Network offline: Changes saved locally, synced when online (follows existing offline-first pattern)\n\n### Mobile Considerations\n\n- Customize Exercise interface uses full-screen sheet on mobile (slides up from bottom)\n- Large touch targets for all controls (minimum 44px)\n- Muscle selection uses scrollable chip buttons (same as Create Exercise Dialog)\n- Image upload supports both camera and gallery selection\n- Keyboard-aware layout - form scrolls when keyboard appears\n\n## Edge Cases\n\n**Original Exercise Definition Deleted:**\n- If a user has overridden an exercise and the original definition is later deleted (e.g., custom exercise deleted by user)\n- The plan exercise continues to work using the overridden values\n- \"Based on: [Original Name]\" shows \"(Deleted)\" indicator\n- User cannot reset to defaults (button disabled with tooltip explaining why)\n\n**Partial Overrides:**\n- User overrides only the name, leaves everything else as default\n- Only the name field shows \"Modified\" indicator\n- Exercise card shows customized name but original image and muscle group\n- This is the expected common case - most users will only customize the name\n\n**Empty Override Values:**\n- User cannot save with empty required fields (name, primary muscle)\n- Validation prevents saving until required fields have values\n- Secondary muscles can be empty (valid to have no secondary muscles)",
